# by-the-book
godot game jam

this is a demo completed for a game jam!! 

currently I have the walking view on the side, and the goal is to kind of have a "papers please" type of gameplay where the player can drag things around

i intended for game design choices such as lighting, ambience effects to tell a story (with the first level being more ominous as the narrative would reflect different generations becoming more hopeful as the recipes pass on to show themes of overcoming generational trauma...)

i wanted levels getting progressively harder as knowledge is lost you must find missing gaps via non written methods ideally

in the future i would add more sound effects, more mechanics (like chopping boards, different forms of ingredients, etc!! i spent a lot of time getting down the design decisions
